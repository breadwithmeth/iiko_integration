# Plan: Add Period Selection to Order Statistics

## Current State
- Backend: `GET /api/orders/stats` accepts single optional `date` parameter (filters orders for that specific day)
- Frontend: Single date picker (`<input type="date">`) defaults to today
- Hook: `useOrderStats(date)` passes only the single date

## Implementation Plan

### 1. Backend Changes (`apps/api/src/modules/orders/routes.ts`)

**Modify the stats endpoint (lines 288-352) to accept:**
- `dateFrom` (optional) - start of period (ISO date string)
- `dateTo` (optional) - end of period (ISO date string) 
- Keep `date` for backward compatibility (if provided, overrides dateFrom/dateTo for single-day query)

**Logic:**
- If `date` provided → filter for that single day (current behavior)
- Else if `dateFrom` and/or `dateTo` provided → filter by date range
- Else → no date filter (all time)

### 2. Frontend Hook Changes (`apps/web/src/api/hooks.ts`)

**Update `useOrderStats` hook (lines 131-139):**
- Accept `dateFrom` and `dateTo` parameters instead of just `date`
- Pass both to query key and API call

### 3. Frontend UI Changes (`apps/web/src/pages/StatisticsPage.tsx`)

**Replace single date picker with Period Selector component:**
- **Preset buttons** (quick selection):
  - "Сегодня" (Today)
  - "Вчера" (Yesterday) 
  - "Последние 7 дней" (Last 7 days)
  - "Этот месяц" (This month)
  - "Прошлый месяц" (Last month)
  - "Этот квартал" (This quarter)
- **Custom range**: Two date inputs (От / До) shown when "Произвольный период" is selected
- **State**: Track `mode: 'preset' | 'custom'` + `preset: string` + `dateFrom` + `dateTo`
- **Default**: "Этот месяц" (This month)

### 4. Export CSV Filename
- Update `exportToCSV` to include period in filename: `order-stats-{dateFrom}-{dateTo}.csv` or `order-stats-{preset}.csv`

## Technical Details

### Backward Compatibility
- Existing `date` parameter still works
- Frontend defaults to "Этот месяц" instead of "Today"

### Date Handling
- All dates in UTC (consistent with current implementation)
- `dateTo` is inclusive (end of day)
- Presets calculate dates client-side, send `dateFrom`/`dateTo` to API

### Files to Modify

2. `apps/web/src/api/hooks.ts` - `useOrderStats` hook  
3. `apps/web/src/pages/StatisticsPage.tsx` - UI with period selector
